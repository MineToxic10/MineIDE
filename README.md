# 🇬🇧 English

## ⌯ 🔗 ▸ What is MineIDE?

A professional **Integrated Development Environment (IDE)** for Android, specifically designed for writing **PocketMine-MP API 5 plugins**. Built by **MineToxic10** and designed with the assistance of **Artificial Intelligence**.

---

## ⌯ ✨ ▸ Key Features

### 🎨 › Design & Appearance
- Multiple themes (Dark, Light, Amoled Black, Dracula, One Dark Pro, Monokai)
- Programming fonts (JetBrains Mono, Fira Code)
- Customizable accent color
- Smooth animations throughout the UI

### 📁 › File Management
- Create files and folders
- Auto-save support
- Full project management with file tree

### 💻 › Code Editor
- Full **syntax highlighting** for PHP
- **Smart autocomplete** for PocketMine-MP API 5
- **Code folding** for classes, methods, and blocks
- **Multi-cursor** editing and **Find & Replace** with regex
- **Minimap**, line numbers, word wrap toggle
- Unlimited **undo/redo** history

### 🔌 › PocketMine-MP API 5 Support
- Autocomplete for all namespaces and methods
- Ready-to-use snippets (`!plugin`, `!command`, `!event`, `!task`...)
- Auto-generate `plugin.yml`
- PHPDoc tooltip for every method

### 🧩 › Built-in Plugin System
- Install additional plugins (`.mide` format)
- Hook system for plugin developers
- Dedicated plugin manager UI

### 🤖 › Built with Artificial Intelligence
This project was designed with the help of AI. The app architecture, autocomplete system, plugin structure, and all documentation were crafted using AI-assisted development.

# 🇮🇷 فارسی

## ⌯ 🔗 ◂ برنامه MineIDE چیست؟

یک محیط توسعه یکپارچه (IDE) حرفه‌ای برای گوشی‌های اندروید است که به‌صورت ویژه برای نوشتن **پلاگین‌های PocketMine-MP نسخه API 5** طراحی شده است. این برنامه توسط **MineToxic10** ساخته شده و با کمک **هوش مصنوعی** طراحی و توسعه یافته است.

---

## ⌯ ✨ ◂ ویژگی‌های اصلی

### 🎨 › طراحی و ظاهر
- تم‌های متنوع (تاریک، روشن، مشکی کامل، دراکولا، وان‌دارک، موناکای)
- فونت‌های برنامه‌نویسی (JetBrains Mono، Fira Code)
- رنگ تاکید قابل تنظیم توسط کاربر
- انیمیشن‌های روان در سراسر برنامه

### 📁 › مدیریت فایل
- ساخت فایل و پوشه
- ذخیره خودکار
- مدیریت کامل پروژه با درخت فایل

### 💻 › ویرایشگر کد
- **رنگ‌آمیزی نحوی** کامل برای PHP
- **تکمیل خودکار هوشمند** برای PocketMine-MP نسخه ۵
- **تاشوی کد** برای کلاس‌ها، متدها و بلوک‌ها
- ویرایش **چندنقطه‌ای** و **جستجو و جایگزینی** با پشتیبانی از عبارات منظم
- **نقشه کوچک کد**، شماره خطوط، و تغییر حالت پیچش متن
- تاریخچه **بازگردانی و بازانجام** نامحدود

### 🔌 › پشتیبانی از پلاگین PocketMine API 5
- تکمیل خودکار تمام فضاهای نام و متدها
- قطعه‌کدهای آماده (`!plugin`، `!command`، `!event`، `!task` و...)
- تولید خودکار فایل `plugin.yml`
- نمایش راهنمای مستند برای هر متد

### 🧩 › سیستم پلاگین داخلی
- قابلیت نصب افزونه‌های اضافی (فرمت `.mide`)
- سیستم قلاب برای توسعه‌دهندگان افزونه
- مدیریت افزونه با رابط کاربری اختصاصی

### 🤖 › ساخته شده با هوش مصنوعی
این پروژه با کمک هوش مصنوعی طراحی شده است. معماری برنامه، سیستم تکمیل خودکار، ساختار افزونه‌ها و تمام مستندات با استفاده از هوش مصنوعی پیاده‌سازی شده‌اند.
